# PyScribe IDE

**PyScribe** — современная, легковесная и производительная среда разработки (IDE) для рабочего стола Windows, разработанная на Python и PyQt5. Интерфейс выполнен в виде эргономичного тёмного воркбенча (VS Code-style), ориентированного на комфортную работу с кодом, проектами и терминалом.

---

## Основные возможности

### 1. Многоязычный редактор кода
- **Подсветка синтаксиса** для более чем 20 языков программирования и разметки: Python, JavaScript, TypeScript, C, C++, C#, Go, Rust, Java, PHP, Ruby, Lua, HTML, CSS, JSON, Markdown, Shell/Bash, YAML, Dockerfile и др.
- **Разделение рабочей области (Split Editor)**: просмотр и редактирование нескольких файлов одновременно (`Ctrl+\`).
- **Быстрый переход и поиск**:
  - Быстрое открытие файлов: `Ctrl+P`.
  - Палитра команд: `Ctrl+Shift+P`.
  - Поиск и замена по файлу: `Ctrl+F` / `Ctrl+H`.
  - Глобальный поиск по проекту во вкладке Search.
- **Интеллектуальное автосохранение** и восстановление рабочих сессий между перезапусками.

### 2. Запуск кода и автоматический поиск компиляторов
- **Автопоиск компиляторов и интерпретаторов**: PyScribe умеет автоматически сканировать систему (переменные PATH, стандартные директории установки SDK и пакетов) и обнаруживать установленные среды разработки:
  - **Python**: системный интерпретатор, виртуальные окружения, Python Launcher.
  - **JavaScript / TypeScript**: Node.js, `tsc`, `ts-node`.
  - **C / C++**: GCC (MinGW/MSYS2), Clang, MSVC (`cl.exe`).
  - **C#**: .NET CLI (`dotnet`), Roslyn/Framework (`csc.exe`).
  - **Go**: `go`.
  - **Rust**: `rustc`, `cargo`.
  - **Java**: `javac`, `java` (Oracle JDK, OpenJDK).
  - **PHP, Ruby, Lua**: соответствующие интерпретаторы.
  - **Shell**: Bash, Git Bash, WSL.
- **Запуск в один клик (`F5`)**: исполнение текущего файла или проекта напрямую во встроенном терминале без необходимости ручной настройки.
- **Управление компиляторами**: отдельная вкладка в настройках позволяет как задать кастомные пути к исполняемым файлам, так и выполнить автоматическое сканирование одной кнопкой.

### 3. Интегрированный терминал
- Встроенная консоль Windows / Shell (`Ctrl+``) с поддержкой нескольких вкладок.
- Удобное управление сессиями: создание вкладок, переключение, остановка процессов (`Ctrl+C`), очистка буфера.
- Связь с редактором: команды сборки и запуска передаются непосредственно в активную терминальную вкладку.

### 4. Управление проектами и файловый менеджер
- **Менеджер проектов**: диалог управления локальными проектами с карточками, историей последних открытых директорий, настройкой команд запуска и безопасным удалением проектов из списка.
- **Древовидный проводник (Explorer)**: полноценная навигация по файловой системе проекта, создание новых файлов и папок, переименование и удаление.
- **Интеграция с Git**: боковая панель контроля версий с отображением текущей ветки, изменённых файлов, индексацией (`Stage All`) и созданием коммитов.

### 5. Встроенные просмотрщики документов
- **Markdown Viewer**: просмотр разметки документации в реальном времени.
- **PDF Viewer**: встроенный просмотр PDF-файлов и спецификаций без необходимости сторонних программ.
- **Hex Viewer**: безопасный шестнадцатеричный просмотр бинарных файлов и исполняемых модулей с защитой редактора от повреждения кодировок.

### 6. Персонализация и темы
- Палитра готовых тем оформления: **Dark**, **Midnight**, **Graphite**, **Nord**, **Light**.
- Гибкая настройка интерфейса: размеры шрифтов редактора и интерфейса, высота панелей, параметры автосохранения.

## Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + P` | Быстрое открытие файла (Quick Open) |
| `Ctrl + Shift + P` | Палитра команд (Command Palette) |
| `Ctrl + ` ` | Показать / скрыть интегрированный терминал |
| `Ctrl + Shift + ` ` | Открыть новую вкладку терминала |
| `Ctrl + \` | Разделить / объединить редактор (Split Editor) |
| `Ctrl + S` | Сохранить текущий файл |
| `Ctrl + Shift + S` | Сохранить файл как... |
| `Ctrl + O` | Открыть файл |
| `Ctrl + N` | Создать новый файл |
| `Ctrl + W` | Закрыть активную вкладку |
| `Ctrl + F` | Панель поиска в файле |
| `Ctrl + H` | Панель замены в файле |
| `F5` | Запустить файл / проект |

## Быстрый запуск из исходного кода

### Требования
- Python 3.10 или новее.
- Операционная система Windows (также поддерживается базовый запуск на Linux).

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/stand4r/PyScribe.git
cd PyScribe
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```
*(Или воспользуйтесь `PyScribe.vbs` для тихого запуска без консольного окна Windows).*

## Сборка автономного `.exe` и установщика

PyScribe поддерживает создание полностью автономного исполняемого файла, не требующего наличия установленного Python на целевом компьютере.

### 1. Сборка портативного `.exe`
Запустите скрипт:
```cmd
build_exe.bat
```
Скрипт выполнит сборку через `PyInstaller` по спецификации `PyScribe.spec`. Готовый бандл появится в папке `dist\PyScribe\`, а главный исполняемый файл — `dist\PyScribe\PyScribe.exe`.

### 2. Сборка инсталлятора (Inno Setup)
После успешной сборки `.exe` запустите:
```cmd
installer\build_installer.bat
```
*(Требуется установленный Inno Setup 6).*  
Установщик `PyScribe-Setup-v<версия>.exe` появится в папке `installer_output\`. Номер версии берётся из файла `VERSION`.

## Архитектура проекта

```text
PyScribe/
├── app/                  # Главные контроллеры и менеджеры приложения
│   ├── application.py    # Точка входа ApplicationManager и запуск Qt-цикла
│   ├── main_window.py    # Главное окно ModernMainWindow и раскладка
│   ├── controller.py     # Контроллер рабочего стола WorkbenchController
│   ├── file_manager.py   # Операции с файлами (открытие, сохранение)
│   ├── project_handler.py# Управление жизненным циклом открытых проектов
│   └── code_runner.py    # Диспетчер выполнения кода
├── core/                 # Ядро анализа, индексации и безопасности
│   ├── analyzers/        # Реестр статических анализаторов файлов
│   ├── logging_config.py # Централизованное журналирование (logging)
│   ├── workspace_index.py# Полнотекстовый и символьный индекс рабочей области
│   └── single_instance.py# Контроль единственного экземпляра приложения
├── widgets/              # Компоненты графического интерфейса (PyQt5)
│   ├── QCodeEditor.py    # Продвинутый редактор кода с подсветкой синтаксиса
│   ├── TerminalWidget.py # Интегрированный многовкладочный терминал
│   ├── Explorer.py       # Дерево проводника файлов
│   ├── ProjectDialog.py  # Диалог управления проектами
│   ├── ProjectManager.py # Модель данных проектов и сохранение состояния
│   ├── GitPanel.py       # Панель работы с Git
│   ├── SettingsWidget.py # Окно настроек IDE и компиляторов
│   ├── DocumentViewerWidget.py # Просмотр документов
│   ├── MarkdownViewerWidget.py # Просмотрщик Markdown
│   ├── HexViewer.py      # Шестнадцатеричный просмотрщик
│   └── WelcomeWidget.py  # Приветственный экран
├── utils/                # Системные вспомогательные утилиты
│   ├── toolchain_detector.py # Поиск компиляторов и формирование команд запуска
│   ├── programs.py       # Менеджер настроек, кеша и сессий
│   ├── settings_manager.py # Управление постоянными настройками
│   └── CSharpCompiler.py # Специфический сервис сборки проектов C#
├── design/               # Темы оформления, стили QSS и шрифты
├── installer/            # Скрипты и конфигурация создания инсталлятора
├── tests/                # Модульные и интеграционные тесты
├── requirements.txt      # Список зависимостей Python
└── main.py               # Корневой запускаемый файл
```
